# Стек и закрепление зависимостей

| Компонент | Фактический выбор | Закрепление и проверка |
| --- | --- | --- |
| Язык/окружение | Python >=3.12, POSIX | Локально Python 3.12.14; CI выбирает 3.12, patch не закреплён и здесь не заявляется |
| Runtime | Только стандартная библиотека | dependencies=[] в pyproject.toml; нет сетевой библиотеки/SDK |
| Сборка | setuptools 80.9.0 | requirements-build.txt: SHA256 062d34222ad13e0cc312a4c02d73f059e86a4acbfbdea8f8f76b28c99f306922; pip --require-hashes |
| Тесты | unittest | Встроен в Python; сейчас 19 тестов с подслучаями правил |
| Контракт | JSON Schema draft 2020-12 | Используется ограниченный валидатор только встроенных ключевых слов, не полный движок |
| Отчёты | JSON/Markdown UTF-8 | ensure_ascii=False; машинные ID/ключи не переводятся |
| Секреты | gitleaks 8.24.3 | SHA256 архива 9991e0b2903da4c8f6122b5c3186448b927a5da4deef1fe45271c3793f4ee29c |
| Actions | checkout v4.2.2, setup-python v5.6.0 | Полные commit SHA в workflows |
| Перенос сборки между задачами | upload-artifact v4.6.2, download-artifact v4.3.0 | Полные commit SHA в release.yml; хранение 1 день |

requirements-build.txt выполняет роль файла закрепления единственной зависимости
сборки; отдельный runtime lock не нужен из-за отсутствия сторонних зависимостей.
Pip — инструмент окружения, его версия не закреплена; он проверяет хеш setuptools.
Локально также проверены git 2.52.0 и Bash 5.2.37, не являющиеся runtime-пакетами CLI.

[ADR](docs/adr/0001-stack.md) объясняет выбор Python вместо Go/TypeScript и отсутствие
сервиса/базы/агента. SOURCE_DATE_EPOCH фиксирует время ZIP; TAR сортирует пути и
нормализует владельца/права/время. Повторные сборки одной среды проверяются SHA256.
Права ZIP между checkout-средами могут различаться: идентичность содержимого
проверяется отдельно. Полная побайтовая воспроизводимость на произвольной OS не заявлена.
