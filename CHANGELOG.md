# История изменений

## 0.1.0a2

- Русская документация, справка CLI, отчёты, описания правил/схем и шаблоны участия.
- Сохранены команды, пути, ключи JSON, идентификаторы и семантика статусов.
- Установка и инструкции среды воспроизводятся из checkout без сохранённого `.venv`.
- Сборка берёт версию из `pyproject.toml`; публикация использует существующий draft,
  явно заданные commit/release ID, проверенный tag и штатный `GITHUB_TOKEN`.
- Новые регрессионные проверки русского вывода и безопасной обработки аргументов.
- Все реальные инфраструктурные лабораторные проверки по-прежнему не выполнены.

## 0.1.0a1

Первый автономный аудитор: закрытая схема JSON, 10 правил, JSON/Markdown,
`pass/fail/unknown/not_run`, проверка актуальности, безопасные файлы, синтетические
примеры, модульные/интеграционные тесты, сборка wheel/исходников и CI с gitleaks.
[Первый выпуск](https://github.com/mejustbox-byte/vps-opsec-auditor/releases/tag/v0.1.0a1)
опубликован с тремя проверенными assets и сохраняется без изменения tag.
