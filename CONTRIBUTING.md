# Участие в разработке

Все документы, пользовательские инструкции, описания правил и заметки к выпускам
пишутся на русском языке. Команды, пути, ключи JSON, статусы, идентификаторы и имена
кода сохраняются. Исходные и существующие теги выпусков не передвигаются.

Используйте существующий изолированный checkout и сохраняйте чужие изменения.
Для установки выполните `bash scripts/setup_environment.sh`; для отдельной проверки
используйте команды из [README](README.md). Изменения проходят через PR и успешный CI.
Проверяйте смысл документации, ссылки, примеры, версию пакета и чистую установку wheel.

Тестовые данные должны быть синтетическими. Запрещены реальные учётные данные, IP,
исходные выгрузки и отчёты в публичном git. Не сканируйте произвольные адреса,
не создавайте платные ресурсы и не используйте реальные учётные данные провайдера.
Новые сетевые компоненты требуют отдельного разрешённого одноразового стенда,
проверки модели угроз и [лабораторного протокола](docs/lab.md).

В PR опишите проблему, изменение поведения, выполненные проверки и ограничения.
Не выдавайте синтетические тесты за проверку провайдера. Первый стабильный выпуск
требует реальных лабораторных свидетельств; до этого выпуски предварительные.
