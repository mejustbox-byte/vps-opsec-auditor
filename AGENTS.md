# Инструкции для последующих циклов

- Вся документация, пользовательская справка, описания правил/схем и notes — на русском.
  Команды, пути, ключи JSON, enum, ID и кодовые имена не переводить. LICENSE сохраняет
  полный стандартный MIT; русское пояснение находится в LICENSE.ru.md.
- Сначала читать README с полным индексом, ARCHITECTURE, CORE-CONTRACT, SECURITY,
  THREAT-MODEL, VERIFICATION и инструкции среды. Все разделы индекса сохранять;
  старые docs не удалять, связывать без противоречий. Не подменять полноту объёмом текста.
- Использовать существующий изолированный checkout; без явного запроса не создавать worktree.
  Проверять git status, сохранять пользовательские изменения. Setup:
  `bash scripts/setup_environment.sh` из корня; не рассчитывать на сохранённый venv.
- Выполнять содержательные unit/integration tests, docs/public-data checks, сборку,
  gitleaks, проверку лицензии и чистую установку пакета. Сверять команды с исходниками.
  Не называть нулевые, пропущенные или непроведённые проверки успешными.
- Синтетические наблюдения не подтверждают live-инфраструктуру. Реальные лаборатории
  явно отмечать НЕ ВЫПОЛНЕНО до отдельного разрешённого стенда. Не создавать платные
  ресурсы, не сканировать произвольные адреса, не применять реальные credentials провайдера.
- Не помещать реальные IP, секреты, raw exports и частные отчёты в git/CI/обсуждения.
  Не раскрывать значения credentials и не обходить аутентификацию.
- Изменения — PR/успешный CI/main. Пользователь разрешил commit/push/PR/merge/release;
  повторного разрешения на эти действия не требуется. Действующие tags не передвигать.
- Перед выпуском проверить точный commit/main CI, tag, existing draft ID, workflow,
  три assets, SHA256, скачивание и чистую установку. Пустой draft не является выпуском.
- После изменений сохранить русские install_script/start_skill среды с фактическими
  командами; сохранение draft не равно публикации snapshot или его восстановлению.
- В итоговом отчёте дать реальные ссылки на PR/merge/release/CI, подтверждённые результаты
  и оставшиеся лабораторные gates. Не приписывать продукту HTTP API или live-сборщики.
