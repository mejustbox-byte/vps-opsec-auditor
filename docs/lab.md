# Одноразовая лаборатория

## Текущие проверки
Только синтетические файлы и автономные тесты; сеть и облачные ресурсы не используются.
Адреса примеров: 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24,
2001:db8::/32; домены .invalid. Эти адреса не сканировать.
Пример контракта не является успешной проверкой реального провайдера.

## Будущая локальная лаборатория
Одноразовые процессы/контейнеры без облачных учётные данные, монтирования host,
privileged mode и доступа к реальному metadata. Порты только loopback, сеть
изолирована; имитация API IAM/MFA/firewall/backup и metadata не содержит токенов.
Манифест сценария фиксирует ожидаемый исход, разрешённую цель, методы и бюджет.
TLS использует временный тестовый CA; host хранилище доверенных сертификатов не изменяется.
DNS/IPv6 проверяются изолированно; недоступный IPv6 отмечается как пропуск с причиной.
Удаляются только ресурсы стенда по манифесту; проверяется отсутствие процессов,
портов, временных учётные данные и файлов. Такой стенд пока не создавался.

## Отдельное условие для стенда провайдера
Нужны разрешение владельца, отдельный одноразовый проект/аккаунт, доказанные права
только чтения, точная область, список разрешённых целей, бюджет, RPO/RTO,
ответственный за удаление и срок жизни. Платные ресурсы в задаче запрещены;
бесплатный реальный стенд также не создаётся. Создание, restore и удаление выполняет
владелец отдельно от аудитора. Фиксируются провайдер/версия, возможности API,
IPv4/IPv6, ожидаемые исходы, частные request IDs и дата. В git только синтетические аналоги.

## Протокол реального тестирования
1. Владелец задаёт цели RPO/RTO, пороги TLS/backup, область и срок стенда.
2. Собирает разрешённые наблюдения портов/панелей/SSH, эффективных firewall/привязок
   IPv4/IPv6, IAM/MFA/восстановления доступа, cloud-init/metadata, DNS/TLS,
   резервного копирования и восстановления. Без перебора паролей и эксплуатации.
3. Хранит исходные данные вне git; обезличивает до schema v1 facts и псевдонимов,
   задаёт source=lab/provider_export/operator, synthetic=false и честное время.
4. Запускает установленный CLI с текущими часами и --fail-on incomplete, сверяет
   каждое правило с ожидаемым результатом. Проверяет безопасные/небезопасные
   конфигурации, устаревание, unsupported MFA, обход IPv6 и неудачный restore.
5. Сохраняет частные ссылки и пропуски охвата. Публикует только синтетические аналоги.
   Выполняет удаление по манифесту и подтверждает отсутствие остатков.

Не выполнены реальные наблюдения портов/SSH/TLS/DNS, IAM провайдера/API/MFA,
облачный firewall/IPv6, гостевые cloud-init/metadata, backup/restore/RPO/RTO.
Причина: отдельный разрешённый стенд не предоставлен; реальные учётные данные запрещены
текущим заданием. Автономные синтетические тесты не заменяют эти проверки.
