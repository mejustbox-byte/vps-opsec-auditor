# Локальная лаборатория для автономного MVP

## Проверенный уровень
Доступен файловый синтетический стенд на Linux/POSIX с Python 3.12. Это не VPS
провайдера и не сетевой стенд. Реальные порты, аккаунты, metadata и restore не проверялись.
Для Windows прямой запуск не поддерживается; WSL2/macOS отдельно **НЕ ПРОВЕРЕНЫ**.

## Повторение без credentials и ресурсов
Из checkout запустите `bash scripts/setup_environment.sh` в своём окружении.
Затем воспроизведите три набора с --at 2026-10-09T01:00:00Z:

- fixtures/safe.json: 10 pass; --fail-on incomplete даёт 0.
- fixtures/unsafe.json: 10 fail; --fail-on fail даёт 1.
- fixtures/missing.json: 10 not_run; --fail-on incomplete даёт 1.

`PYTHONPATH=src python3 -m unittest discover -s tests -v` проверяет все правила,
IPv6 включён/выключен/неизвестен, пороги, stale/future, unsupported/error, файлы,
ошибочный JSON и русский вывод. Временные файлы тестов удаляются автоматически.
Не подменяйте тестовые IP реальными: документационные диапазоны не сканируются.
Для отдельного отчёта используйте временную папку и --output с новым именем.

## Следующий независимый уровень
Сетевая имитация требует одноразовых процессов/контейнеров без host mounts,
privileged mode, реальных credentials и доступа к настоящему metadata; сейчас её нет.
Провайдерская лаборатория — отдельное разрешение, область, бюджет, отрицательные
сценарии и удаление. Не выдавайте успешные файловые тесты за её проверку.
